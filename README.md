## 📖 परिचय (Overview)

उत्तर प्रदेश एवं अन्य हिन्दी भाषी राज्यों में बूथ लेवल अधिकारियों (BLOs), तहसीलदारों, एवं चुनाव सहायकों को विभिन्न निर्वाचक नामावलियों (जैसे विधानसभा सूची, पंचायत मतदाता सूची, SIR सूचियां) के मिलान में भारी कठिनाइयों का सामना करना पड़ता है।

मैनुअल टाइपिंग, हस्तलिखित प्रविष्टियों और OCR स्कैनिंग के कारण एक ही व्यक्ति का नाम दोनों सूचियों में भिन्न-भिन्न रूपों में दर्ज होता है:
* **मात्राओं के अंतर**: `जमीलखां` vs `जमीलखाँ`, `सुनील` vs `सुनिल`, `खॉं` vs `खाँ`
* **आधे अक्षर व संयोग**: `प्रसाद` vs `प्साद`, `चन्दन` vs `चंदन`, `कृष्ण` vs `क्रष्ण`
* **समान ध्वनि वर्ण (Letter Swaps)**: `श/ष/स`, `व/ब`, `ण/न`, नुक्ता (`ग़` vs `ग`)
* **अतिरिक्त उपनाम / उपाधियां**: `सुनील` vs `सुनील कुमार`, `शीला` vs `शीला देवी`, `कु० अंजली`, `श्रीमती`
* **स्पेसिंग व टंकण त्रुटियां**: `योगेश कुमार` vs `योगेशकुमार`, `ओमप्काश` vs `ओमप्रकाश`, `घासू` vs `धांसू`, `सोरव` vs `सौरभ`
* **गलत आयु व लिंग**: विभिन्न सूचियों में आयु और लिंग की प्रविष्टियों में मानवीय भूलें

**Electoral Roll Check** एक आधुनिक, उच्च-प्रदर्शनयुक्त ऑफलाइन डेस्कटॉप एप्लिकेशन है जो उन्नत देवनागरी सामान्यीकरण, ध्वन्यात्मक कुंजियों (Phonetic Keys), तथा हंगेरियन इष्टतम मिलान (Hungarian Algorithm via `scipy.optimize.linear_sum_assignment`) का उपयोग करके 1-to-1 निष्पक्ष मिलान प्रदान करता है।

## 🛡️ गोपनीयता एवं डेटा सुरक्षा (Hard Rules)
1. **100% ऑफलाइन**: यह सॉफ्टवेयर किसी भी प्रकार का नेटवर्क कॉल, टेलीमेट्री या क्लाउड API का उपयोग नहीं करता। मतदाता का निजी डेटा सदैव आपके कंप्यूटर पर सुरक्षित रहता है।
2. **मूल हिन्दी प्रारूप**: निर्यात की जाने वाली रिपोर्टों में डेटा का कोई अनुवाद (Translation) या लिप्यंतरण (Transliteration) नहीं किया जाता; सभी नाम मूल हिन्दी में रहते हैं।
3. **कभी भी केवल VLOOKUP समानता नहीं**: प्रत्येक गैर-समान रिकॉर्ड बहुआयामी स्कोरिंग से गुजरता है।
4. **सहोदर सुरक्षा (Sibling Guard)**: पिता का नाम समान होने पर भी भाई-बहनों (जैसे `शशि देवी` vs `राशि देवी`, `सीता देवी` vs `सुधा देवी`) को कभी भी स्वतः "मिला" नहीं माना जाता।

## 🖥️ उपयोगकर्ता मार्गदर्शिका (Step-by-Step User Guide)

### चरण 1: फ़ाइलें आयात करें (Import Page)
1. बाएँ पैनल में **सूची A** (संदर्भ सूची - उदा० विधानसभा रोल) की फ़ाइल चुनें।
2. दाएँ पैनल में **सूची B** (सत्यापन सूची - उदा० पंचायत रोल) की फ़ाइल चुनें।
3. यदि आवश्यक हो तो शीट और शीर्षक पंक्ति (Header Row) का चयन करें।
4. नीचे 50 पंक्तियों का पूर्वावलोकन देखें।
5. **"स्तंभ मिलान पर आगे बढ़ें ➔"** बटन पर क्लिक करें।

### चरण 2: स्तंभों का मिलान करें (Mapping Page)
1. सॉफ्टवेयर स्वचालित रूप से हिन्दी शीर्षकों के आधार पर स्तंभों का सुझाव देता है।
2. **कागज़ी क्रम संख्या (Roll Serial No.)**: दोनों फाइलों के 'क्र०', 'क्रमांक' या 'Sl No' कॉलम को मैप करें ताकि कागज़ी रजिस्टर में मतदाता तुरंत मिल सके (यह स्कोरिंग को प्रभावित नहीं करेगा)।
3. मतदाता का नाम, पिता/पति का नाम, आयु, लिंग, मकान संख्या और वार्ड चुनें।
4. प्राथमिकताओं (Paper Ref, Must match, High, Medium, Low, Bonus) को आवश्यकतानुसार समायोजित करें।
5. भविष्य के लिए प्रोफ़ाइल सहेजें (उदा० "पंचायत vs विधानसभा")।
6. **"🚀 मिलान प्रारंभ करें"** पर क्लिक करें।

### चरण 3: परिणाम एवं रिपोर्ट देखें (Results & Export Page)
1. स्क्रीन पर 4 सारांश कार्ड दिखाई देंगे:
   * 🟢 **मिला (Matched)**: उच्च सटीकता वाले प्रमाणित मतदाता।
   * 🟡 **जाँचें (Needs Review)**: आंशिक वर्तनी या विवरण भिन्नता (सत्यापन आवश्यक)।
   * 🔴 **लापता (Missing)**: सूची A में न पाए गए मतदाता।
   * 🔵 **केवल सूची A में**: संदर्भ सूची में शेष मतदाता।
2. **"📊 विस्तृत Excel रिपोर्ट (.xlsx) डाउनलोड करें"** पर क्लिक करके आधिकारिक वर्कबुक सुरक्षित करें।
3. **"📄 सत्यापन PDF प्रपत्र (.pdf) डाउनलोड करें"** पर क्लिक करके प्रिंट-अनुकूलित पीडीएफ प्राप्त करें।

### चरण 4: स्थलीय सत्यापन स्क्रीन (Review Page & Live Updated Export)
BLOs को फील्ड में सत्यापन के लिए समर्पित शक्तिशाली स्क्रीन:
* **बायाँ पैनल**: सत्यापन योग्य मतदाता का विवरण, मूल फ़ाइल पंक्ति संख्या और आंतरिक ID।
* **दायाँ पैनल**: संदर्भ सूची के शीर्ष-3 प्रत्याशी, मिलान स्कोर %, विस्तृत कारण, और **अक्षर-स्तरीय रंगीन अंतर (Devanagari Diff Highlighting)**।
* **📥 अद्यतन Excel डाउनलोड करें (Direct Updated Export)**:
  * सत्यापन पूरा होने पर स्क्रीन छोड़े बिना एक क्लिक में अद्यतन 5-शीट Excel रिपोर्ट डाउनलोड करें।
  * आपके द्वारा स्वीकृत किए गए मतदाता स्वतः `'3. मिला'` शीट में ट्रांसफर हो जाते हैं और 'सारांश' शीट के आँकड़े स्वतः अपडेट हो जाते हैं।
* **⚡ उच्च समानता वाले स्वतः स्वीकारें (>85%)**:
  * 85% से अधिक स्कोर वाले सभी स्पष्ट प्रत्याशियों को एक क्लिक में स्वीकार कर समय बचाएँ।
* **कैफियत व फील्ड टिप्पणियां (Preset Field Remarks)**:
  * ड्रॉपडाउन से त्वरित चयन: `मौके पर भौतिक सत्यापन द्वारा सत्यापित`, `मृतक मतदाता (फॉर्म-7 अपेक्षित)`, `विवाहित / अन्यत्र स्थानांतरित`, `दोहरा नाम (Duplicate)`, या अपना कस्टम विवरण दर्ज करें। ये टिप्पणियां सीधे एक्सेल में दर्ज होती हैं।
* **लाइव प्रगति ट्रैकर (Progress Badge)**:
  * कितने मतदाता सत्यापित हो चुके हैं और कितने लंबित हैं, इसका रीयल-टाइम प्रतिशत व ट्रैकर।
* **सुविधाजनक कीबोर्ड शॉर्टकट**:
  * `1` दबाएँ ➔ प्रत्याशी 1 को स्वीकारें
  * `2` दबाएँ ➔ प्रत्याशी 2 को स्वीकारें
  * `3` दबाएँ ➔ प्रत्याशी 3 को स्वीकारें
  * `M` दबाएँ ➔ "मिला नहीं (लापता)" चिह्नित करें
  * `S` दबाएँ ➔ अगले मतदाता पर जाएँ
  * `←` / `→` ➔ पिछले या अगले मतदाता पर नेविगेट करें

## 🛠️ डेवलपर गाइड (Developer & Build Instructions)

### 1. वातावरण तैयार करना (Environment Setup)
```bash
# रिपोजिटरी में जाएँ
cd VoterNameCheckApp

# निर्भरताएँ स्थापित करें
pip install -r requirements.txt
```

### 2. नमूना डेटा तैयार करना (Generate Sample Datasets)
```bash
python scripts/generate_samples.py
# sample_data/voter_list_A.xlsx और voter_list_B.xlsx तैयार होंगे
```

### 3. स्वचालित परीक्षण चलाना (Run Automated Unit & E2E Tests)
```bash
python -m pytest voter_match/tests/ -v
# सभी 42 टेस्ट उत्तीर्ण (5,000-पंक्ति बेंचमार्क: python scripts/benchmark.py 5000)
```

### 4. एप्लिकेशन चलाना (Run Desktop App)
```bash
python voter_match/app.py
```

### 5. Windows Exe पैकेजिंग (PyInstaller Build)
```bash
pyinstaller build.spec
# dist/ElectoralRollCheck.exe — एकल स्टैंडअलोन फ़ाइल (Python स्थापित करने की आवश्यकता नहीं)
```

### 6. एकल सेटअप इंस्टॉलर बनाना (Inno Setup Installer)
1. [Inno Setup 6](https://jrsoftware.org/isdl.php) स्थापित करें।
2. `installer/setup.iss` को Inno Setup Compiler में खोलें।
3. **Compile** (Ctrl+F9) दबाएँ।
4. `installer_output/ElectoralRollCheck_Setup_v1.0.0.exe` एकल इंस्टॉलर तैयार हो जाएगा।
